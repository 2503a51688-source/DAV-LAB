# 📊 DAV Lab Assignments

A collection of lab assignments for the **Data Analysis & Visualization (DAV)** course.  
This repository contains code, datasets, and documentation for experiments covering data manipulation, analysis, and visualization using Python.

---

## 📘 Course Overview

This lab focuses on practical implementation of data analysis and visualization techniques using popular Python libraries such as:

- **NumPy** – Numerical computing  
- **Pandas** – Data manipulation and analysis  
- **Matplotlib** – Data visualization
